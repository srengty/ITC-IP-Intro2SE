# Lab 08 - Project progress updates
In this lab you will be asked to report the progress of your project.  

## Tasks done last week
Each student is required to report the tasks they have completed in the previous week. This includes:
- A summary of the work accomplished.
- Any challenges faced and how they were overcome.
- Key milestones achieved.
- Code snippets or screenshots demonstrating completed features.
- Time spent on each task.
- Any deviations from the original plan and reasons for those changes.
- Lessons learned from the completed tasks.

## Tasks to be done this week
Students should outline the tasks they plan to undertake in the upcoming week. This section should include:
- A detailed list of tasks and objectives.
- Estimated time for each task.
- Dependencies or prerequisites for each task.
- Expected challenges and strategies to address them.
- How these tasks align with the overall project timeline and goals.
- Any resources or support needed to complete the tasks.

## Problems (stuck)
Students should identify any problems or obstacles they are currently facing that may hinder their progress. This section should cover:
- A clear description of the problem.
- The impact of the problem on the project timeline.
- Steps already taken to resolve the issue.
- Any assistance or resources required to overcome the problem.
- Suggestions for potential solutions or alternative approaches.

## Weekly Progress Report Template
To facilitate consistent reporting, students can use the following template for their weekly progress updates:

```markdown
# Weekly Progress Report - Week [X]
## Tasks Done Last Week
- [Task 1]: Description, time spent, challenges, milestones, code snippets/screenshots
- [Task 2]: Description, time spent, challenges, milestones, code snippets/screenshots
## Tasks to be Done This Week
- [Task 1]: Description, estimated time, dependencies, expected challenges, alignment with project
- [Task 2]: Description, estimated time, dependencies, expected challenges, alignment with project
## Problems (Stuck)
- [Problem 1]: Description, impact, steps taken, assistance needed, potential solutions
- [Problem 2]: Description, impact, steps taken, assistance needed, potential solutions
```
