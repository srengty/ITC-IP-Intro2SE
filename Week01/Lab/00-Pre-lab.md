# Environment Setup
Softwares needed:
- [Git for (Windows/Linux)]([https://](https://git-scm.com/downloads))
- [Visual studio code](https://code.visualstudio.com/Download)
  - Install Git extension in VS Code (if not included by default)
  - Install Gitlab extensions in VS Code: for GitLab integration
  - Install GitHub extensions in VS Code: for GitHub integration
  - Install Java Extension Pack in VS Code: for Java development
  - Install Error Lens extension in VS Code: for enhanced error reporting
- [Java JDK 21 or above](https://www.oracle.com/java/technologies/javase-jdk21-downloads.html)

# Group Formation
Form groups of 2-4 members. Each group will work together on the lab assignments throughout the course.

Team members selection criteria:
- Diverse skill sets
- Good communication skills
- Commitment to the project
- Availability for regular meetings
- Shared interest in the project topic
- Ability to collaborate effectively
- Respect for different perspectives and ideas
- Willingness to learn from each other
- Problem-solving skills
- Time management skills
